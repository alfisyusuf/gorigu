Panduan Praktikum SQL Server

Khusus Pengguna MacBook (Apple Silicon M1/M2/M3)

Alternatif SSMS menggunakan Docker dan DBeaver untuk Modul 3 & 4.

Halo! Karena SQL Server Management Studio (SSMS) hanya tersedia untuk OS Windows, pengguna Mac M1 tidak bisa menginstalnya secara langsung. Sebagai solusinya, kita akan menggunakan Azure SQL Edge (SQL Server versi teringan yang jalan di Mac) via Docker, dan menggunakan DBeaver sebagai GUI (pengganti SSMS). Ikuti langkah-langkah di bawah ini secara berurutan.

1

Menjalankan SQL Server di Mac M1

Buka aplikasi Terminal di Mac kamu. Salin dan jalankan perintah Docker di bawah ini. Perintah ini akan mengunduh dan menyalakan SQL Server di latar belakang.

docker run --cap-add SYS_PTRACE -e 'ACCEPT_EULA=1' -e 'MSSQL_SA_PASSWORD=sa12345' -p 1433:1433 --name sql_server_m1 -d mcr.microsoft.com/azure-sql-edge
  • Pastikan aplikasi Docker Desktop sudah dalam keadaan terbuka/berjalan.
  • Password disetel ke sa12345 agar sesuai dengan modul praktikum.
2

Mengonfigurasi Koneksi DBeaver

Buka aplikasi DBeaver. Kita akan menghubungkannya ke database yang baru saja dinyalakan di Step 1.

  1. Klik icon steker 🔌 (New Database Connection) di kiri atas, pilih SQL Server.
  2. Pada tab Main, isi pengaturan berikut:
    • Host: localhost
    • Port: 1433
    • Username: sa
    • Password: sa12345
  3. Pindah ke tab Driver Properties (ini sangat penting!).
  4. Cari pengaturan bernama TrustServerCertificate, ubah nilainya menjadi true.
    (Ini adalah pengganti langkah Encrypt=False di modul SSMS).
  5. Klik Finish. Jika muncul prompt untuk Download Driver, klik Download.
3

Penyesuaian Modul 3: DDL & Backup/Restore

Membuat "New Query" (Editor SQL)

Di modul tertulis klik ikon "New Query". Di DBeaver, caranya: Klik Kanan pada koneksi server di panel kiri -> pilih SQL Editor -> New SQL Script (atau tekan F3). Gunakan jendela ini untuk menjalankan skrip CREATE DATABASE, CREATE TABLE, dan ALTER TABLE. Untuk mengeksekusi script, blok kode lalu klik tombol "Play" oranye (Ctrl+Enter / Cmd+Enter).

Catatan Backup / Restore (GUI)

Di modul, backup disimpan di C:\Program Files\... (Path Windows). Karena kamu pakai Mac, ini tidak akan berhasil.

Cara DBeaver: Klik kanan pada Database yang ingin di-backup -> pilih Tools -> Backup. Simpan file .bak di folder Documents atau Desktop kamu. Untuk Restore, gunakan menu Tools -> Restore.

4

Penyesuaian Modul 4: DML (Manipulasi Data)

Mengganti "Edit Top 200 Rows"

Modul menyuruh klik kanan tabel lalu "Edit Top 200 Rows". Di DBeaver, fiturnya jauh lebih mudah:

  1. Buka panel kiri, masuk ke Databases -> (Nama DB kamu) -> Schemas -> dbo -> Tables.
  2. Klik Ganda (Double-click) pada nama tabel (misal: Mahasiswa).
  3. Di sebelah kanan, pilih tab Data (di sebelah tab Properties).
  4. Untuk menambah data, klik tombol + di bagian bawah (Add new row).
  5. Untuk mengubah data, klik ganda pada sel yang ingin diedit, lalu ketik nilai barunya.
  6. Untuk menghapus data, klik kanan pada baris -> Delete.
  7. Setelah selesai edit/tambah/hapus, WAJIB klik ikon Disket (Save) di bawah untuk menyimpan perubahan ke database.

Eksekusi Script DML (SELECT, UPDATE, DELETE)

Sama seperti Step 3. Buka SQL Editor, ketik atau copas script dari modul (contoh: SELECT * FROM Mahasiswa). Klik ikon Play oranye di sebelah kiri editor untuk melihat hasil query di panel bawah.

Semangat praktikumnya! Jangan lupa screenshot tugasnya ya. 🚀

Kunci slide

Slide 4 (PGK): A, B, C benar; D salah (tanda pendengar keliru). fp = 600 × 320/370 ≈ 518,9 Hz.

Slide 5 (B/S): Benar – Benar – Salah. WBC = 2×10⁵ J; ΔU siklus = 0 tetapi W netto = luas ≠ 0 (≈ −1,3×10⁵ J).

Kunci worksheet

Soal 1: A, B, C benar; D salah. fp = 800 × 345/315 ≈ 876,2 Hz; sepeda berhenti: 800 × 340/315 ≈ 863,5 Hz (< 876 Hz).

Soal 2: Benar – Salah – Benar. WAB = (4×10⁵)(3) = 1,2×10⁶ J. B→C: W = 0, tekanan turun → T turun → ΔU < 0 → Q < 0 (melepas kalor). Siklus searah jarum jam → W netto positif.

Miskonsepsi yang sering muncul

  • Tanda (+/−) tertukar: ingat pendengar mendekat (+) di atas, sumber mendekat (−) di bawah.
  • Menganggap “ΔU = 0 berarti usaha nol” padahal Q netto = W netto.
  • Lupa isokhorik W = 0 dan isobarik W = P·ΔV.
  • Arah siklus: searah jarum jam → W netto positif; berlawanan → negatif.

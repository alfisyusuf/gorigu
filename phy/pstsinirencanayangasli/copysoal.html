🚀 LMS Copy Helper (Versi HTML Murni)

Alat ini dirancang khusus untuk menghindari masalah MathJax di LMS. Semua rumus fisika telah dikonversi menggunakan tag HTML standar seperti <sub>, <sup>, dan simbol khusus (misal: &mu; &times; &radic;).

Cara Penggunaan: Klik tombol Copy di sebelah teks yang ingin disalin, lalu Paste ke editor soal/jawaban di LMS Anda (mode Source/HTML).

✅ Berhasil disalin ke clipboard!

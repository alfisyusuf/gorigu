🚀 LMS Copy Helper Pro

Berbeda dengan versi sebelumnya, alat ini TIDAK merender LaTeX menjadi MathJax elemen panjang di browser Anda, karena hal tersebutlah yang menyebabkan HTML hancur saat Anda menempelkannya di mode Source LMS (tag <mjx-container> tercopy ke LMS).

Cara Kerja: Alat ini membaca murni kode HTML (termasuk kode $ LaTeX dan tag <svg>), lalu saat diklik Copy, alat ini akan menambahkan CDN script dan membungkus soal/jawaban Anda agar LMS Anda yang akan merendernya nanti.

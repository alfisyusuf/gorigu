Asesmen Kelas 8A
Apps Script hitungNilai()

Bobot: tugas 30%, UTS 30%, UAS 40%. Nilai minimal untuk tuntas: 75.

Empat sesi, dari lembar kosong sampai dasbor hasil belajar

Untuk guru, dosen, dan pengembang pendidikan yang ingin mengurangi kerja manual saat menilai. Tidak perlu pengalaman pemrograman.

  1. 1

    Menyusun lembar nilai yang rapi

    Struktur kolom untuk data siswa, validasi input agar nilai tidak salah ketik, dan rumus dasar untuk rata-rata, predikat, dan ketuntasan.

    Lembar nilai yang siap dipakai satu kelas.

  2. 2

    Mengenal Apps Script

    Membuka editor skrip, menulis fungsi pertama dalam JavaScript, memberi izin akses, dan menjalankannya dari menu atau tombol.

    Fungsi pertama yang membaca dan menulis ke Sheets.

  3. 3

    Mengotomasi penilaian

    Menghitung nilai akhir, menentukan status tuntas atau remedial, merekap per kelas, dan mengirim hasil ke siswa lewat email.

    Satu klik untuk menilai dan mengirim hasil.

  4. 4

    Google Forms dan dasbor hasil belajar

    Menyambungkan kuis di Forms ke Sheets, memicu penilaian otomatis saat siswa mengirim jawaban, dan menampilkan grafik ketuntasan.

    Alur kuis sampai laporan tanpa input manual.

hitungNilai.gs Contoh dari sesi 3 
function hitungNilai() {
  const sh = SpreadsheetApp.getActiveSheet();
  // kolom B-D: tugas, UTS, UAS
  const baris = sh.getRange(2, 2, sh.getLastRow() - 1, 3).getValues();

  const hasil = baris.map(([t, uts, uas]) => {
    const nilai = t * 0.3 + uts * 0.3 + uas * 0.4;
    return [Number(nilai.toFixed(1)),
            nilai >= 75 ? 'Tuntas' : 'Remedial'];
  });

  // tulis ke kolom E-F
  sh.getRange(2, 5, hasil.length, 2).setValues(hasil);
}
